Campaign principles — inherited from the EL campaign, binding

  1. Probe-first: one short smoke gated before any sweep. Every case has a RUNBOOK.md (design → gates → job numbers → verdicts); every quantitative claim becomes a datasheet row (expected / source / measured / tolerance / verdict). FAILs recorded honestly with attribution, never tuned around.

  2. Independent estimators beat tighter tolerances (the EL Couette lesson): wherever possible each stage carries two routes to the same number (e.g. force-integral vs momentum-balance; wall force vs bed weight).

  3. Bitwise twins + A/B worktrees settle “pre-existing vs ours”.

  4. Master/worker asymmetry discipline: rank 0 has no PE in parallel mode; diagnostics must be collective-safe in rank-asymmetric paths.

  5. Mesh fixtures need git add -f (.gitignore excludes *.tri/*.par); per-case pinned example.json (never the shared libs/pe/pe/interface/example.json scratch file).

  6. The user pushes; agent commits only. FF commits end with the standard Co-Authored-By line. Never push libs/pe.

Benchmark 2 — Hasimoto periodic array drag (D1.1) CLOSED

Hasimoto's 1959 paper is applied mathematics, not a simulation study, and the problem it settles is a specific one. Build the Stokes flow through a periodic array of spheres the obvious way — by superposing the disturbance each sphere would produce in isolation — and the lattice sum diverges. Burgers had pointed this out in 1941, and the models that followed (his own diffuse force field, Brinkman, Debye & Bueche) worked around the divergence rather than resolving it.

Hasimoto's resolution is to expand velocity and pressure as Fourier series over the reciprocal lattice and then take seriously what the k = 0 mode says. It gives P₀ = F/τ₀ (eq. 2.14): the force on each sphere is balanced by a mean pressure gradient across the unit cell of volume τ₀. That term is not optional bookkeeping — omitting it is precisely what makes the sums diverge, and with it in place they are finite. The remaining sums are then evaluated by Ewald's theta-transformation, the same device used to compute Madelung constants for ionic crystals; in Hasimoto's reading the lattice behaves like unit charges embedded in a neutralizing uniform background, and that background is the mean pressure gradient.

Applied to a dilute cubic lattice of spheres of radius a, the result gives the drag on any one sphere as a function of volume concentration alone: F = 6πμaU / (1 − κa), with κa = 1.7601 φ1/3 for the simple-cubic lattice (his Table 1), and the §5 refinement carrying it to K = 1/(1 − 1.7601 φ1/3 + φ − 1.5593 φ²). K exceeds 1 always: each sphere sits in flow already retarded by its own periodic images, so an array drags harder than an isolated sphere.

For validating the FBM that combination is unusually good. The reference is analytic — no measurement uncertainty in the target, unlike a PIV curve. The flow is genuinely periodic, so it exercises exactly the machinery a walled case like ten Cate can never touch (as this campaign found out the hard way). And the Stokes regime removes inertia, time accuracy and particle motion from the comparison, leaving the spatial discretization of the interface as essentially the only error source left standing.

Setup & expectation

A single fixed sphere of radius r = 1/6 sits at the centre of a periodic unit cell, which makes it one member of an infinite simple-cubic array at solid fraction φ = 0.0194. A uniform body force drives Stokes flow through the cell (Re ≈ 3 × 10⁻³) and the measured drag is compared with Hasimoto's 1959 dilute-array expansion, which gives K = 1.8322 at this φ. Nothing moves, so the case isolates the accuracy of the fictitious-boundary force integral on a stationary interface. It also turned out to be the only case in either campaign that genuinely exercises periodic boundaries — which is how it found the defect below.

The campaign's headline: a ladder that converged beautifully — onto the wrong answer

The first four rungs converged at apparent order ~1.7 — and settled on a −8.9% asymptote. A convergent ladder that misses the analytic value cannot be a resolution problem, and the walled ten Cate case already certified the same force integral to +0.03% against ten Cate's LBM. That pointed at the one ingredient the walled case never touches: periodicity.

A code trace found it. The Q2/E013 communicator was built by a non-periodic octree search, so it contained zero periodic DOF pairs — and that communicator gates every Q2 exchange and the parallel pressure solve. Every “periodic” face in the code base was in fact being solved traction-free. A decisive experiment confirmed it before any code was written: on a plane that periodicity makes a symmetry plane, max|u_x| / max|u_z| came out at 0.102 — the faces were breathing at 10% of the driving velocity.

The fix (2026-08-03) and the gates it had to pass

parentcomm.f90 now builds a second, parallel periodic vertex-share table (myVERTLINKPER) and unions it into the Q2 communicator gate. The probe has to sweep all 26 periodic images: single-axis probing leaves edge and corner DOFs partially coupled on a 3×3×3 torus and diverged to NaN — periodic edges and corners matter as much as faces.

  • PASSWalled bitwise twin — a non-periodic deck reruns byte-identical on the new binary. The fix is a strict no-op off the periodic path, so every walled ten Cate result stands untouched.
  • PASSu_x plane test — the symmetry-plane ratio drops from 0.102 to 1.75 × 10⁻⁹, and matched points on opposite faces agree to 1 × 10⁻²⁰. The faces are genuinely coupled.
  • PASSCommunicator census — PERIODIC_COMM reports 702 = 27 × 26 neighbour pairs on the QBOX9 torus (every rank now neighbours every other rank), 386 of them periodic-only and previously absent entirely.
  • PASSEL momentum re-check — the EL campaign's Newton-pair gate, rerun on the fixed binary: residual 5.08 × 10⁻²¹, drift 5.32 × 10⁻⁸. Both hold, now on a box that is actually periodic.
  • guardsTwo failure modes are now refused rather than mis-solved: MUMPS as coarse solver on periodic decks (the global numbering swaps periodic labels instead of merging them), and non-axis-uniform partitions — periodic runs need a Cartesian axis-uniform partition so subdomain faces coincide with their images, and METIS graph partitions are invalid.

Closure — the residual ladder is fully itemized, nothing unexplained

Two measurable discretization terms account for what is left. First, the indicator-volume error per rung, taken from each run's own fluid fraction against the analytic 0.9806075: the L2 discrete sphere is +0.95% in radius, L3 is −0.43%, L4/L5 are ≲0.05%. Independent cross-check at a second volume fraction — the closure model holds, and the last open thread closes

The closure above was built on a single φ, so the honest test is a different one. The φ = 0.0082 case (r = 0.125, D/h = 18) is the natural candidate, and it had been the campaign's most stubborn anomaly: a deficit roughly twice the main ladder's at matched resolution, which defeated the radius, confinement and parasitic-drag explanations one after another. Rerun on the fixed binary it gives K = 1.5071 against the analytic 1.5304 — −1.52%, where before the fix it read −19.2%.

So the anomaly was the traction-free box all along, and it punished the more dilute case harder. That matches the image-strength reading taken at the time, which found only ~45% of the confinement captured at φ = 0.0082 against ~80% at φ = 0.019 — a smaller sphere leans more heavily on its periodic images, so losing them costs more. What remains is ordinary O(h) interface widening: the implied coefficient is c ≈ 0.09 at D/h = 18 (using the φ-correct sensitivity 1.506) against the main ladder's 0.12–0.17, and the indicator-volume error here is negligible at ΔV/V = +7 × 10⁻⁴. The same two-term error model, at a φ it was not fitted to.

One caveat, kept rather than tidied away: the settled force overshoots f·V_cell by +0.96% — essentially unchanged from the pre-fix +0.97%, so it is not a periodicity artifact but something case-specific (the off-centre sphere at 0.375³, plus a slow settling tail). Reading K with the momentum-balance force instead gives −2.46%. Both readings close the anomaly; neither is hidden.

Applied to production resolution — what D/h = 3–4 actually buys RECORDED

The ladder above starts at D/h = 6 and climbs to 48. Because this is a closed benchmark being applied rather than a new one, it is a probe, not a rung.

Both land in the same place: the drag is about 10% low, and the closure model built on the fine ladder still describes it. The a_eff = a + 0.14 h model was used to predict both deficits blind — −12.1% and −10.0% — and landed within 1–3 pp of what the probes measured, with an implied coefficient c = (a_eff − a)/h of 0.10–0.15 against the fine ladder's 0.12–0.17. Practitioner verdict — reading a production run at D/h = 3–4
  • correctableMean drag comes out at ≈ 90% of true — low by 9–12%, but systematically low, not randomly. It is therefore correctable: inflate the effective radius by 0.14 h, or equivalently boost drags by sens(φ)·0.14·h/a. A known bias with a model is a far better position than an unknown one.
  • noiseIndividual particle forces carry roughly 8–15% rms grid noise at these resolutions, extrapolating the O(h) noise floor down from the measured ladder. Collective quantities — mean drag, bed pressure drop, effective viscosity — average this away; a single particle's trajectory does not.
  • sub-gridEverything within ~2 cells of contact is sub-grid (the D2.1 crossover rule), and at D/h = 3–4 two cells is half a diameter. All near-contact physics is therefore the contact model's job, not the flow solver's — which makes contact parameters physics to be tuned, exactly as the DKT friction finding concluded.
  • confirmedThe same question asked of a crowd rather than one sphere gives the same answer: the production-resolution array runs in D3.1 land at ~85–90% of converged mean drag with a single ≈1.15 correction. Single-sphere and array-level evidence agree.

Benchmark 3 — drafting–kissing–tumbling (D2.3) CLOSED

Setup & expectation

Two equal spheres are released in-line, one above the other, in a closed 6d × 6d × 24d column at Galileo number Ga ≈ 80. The classical expectation (Fortes, Joseph & Lundgren 1987; Glowinski et al. 2001) is a three-phase sequence: the trailing sphere is drafted into the leader's wake and accelerates, the pair kisses and falls briefly as a doublet, then the doublet is unstable broadside-on and tumbles apart. Because the sequence is symmetry-breaking and chaotic after contact, the gates are mechanism-level — phase sequence and kissing time, not point values.

Axisymmetric smoke — drafting and kissing confirmed

Drafting is unambiguous over t ≈ 10–18: the trailing sphere reaches −0.499 against the leader's −0.427. What it means, and the rule that follows

Two real spheres touching in a liquid are separated by a lubrication film that transmits essentially no tangential traction. The contact model here is a dry frictional one — the HCAF material default μ_s/μ_d = 0.1/0.05 — and a dry frictional contact pins the contact point and freezes the Fortes instability. The blocker was never the fluid solver; it was a contact parameter quietly doing physics.

Guideline for DKT-class simulations: run with ~zero contact friction, or with a lubricated-contact model. More generally — and this is the transferable lesson — contact parameters are physics, not stabilizers. Defaults chosen to make a granular run behave will suppress genuine fluid-mediated instabilities, silently and without any diagnostic firing.

Benchmark 4 — sphere–wall lubrication crossover (D2.1) RULE v1 DELIVERED

Setup & expectation

A sphere approaching a flat wall feels a drag that diverges as 1/gap — Brenner's 1961 exact solution for perpendicular approach. No fixed mesh can resolve that divergence all the way down, so the practical question is not whether the resolved force falls off the analytic curve but where: below which gap must a sub-grid lubrication correction take over? That threshold is the number every near-contact simulation needs and the one the campaign had been carrying as a guess.

Stage 1 — read it off the ten Cate tails, for free

Every ten Cate run ends with a sphere approaching the bottom wall, so the data already existed. Only E1 is honest here — at Re = 1.5 the approach is quasi-steady (inertia diagnostic 0.04), while E2–E4 are contaminated by unsteadiness rather than resolution. E1 tracks Brenner to within −6…−9% at a gap of one radius, and departs by 20% at a gap of 1.2–1.3 h. Provisional, and already 4× less conservative than the ad-hoc threshold in use. RECORDED

Stage 2 — the definitive constant-velocity protocol

The free variant confounds approach speed with gap. Driving the sphere at constant V = 0.02 (μ = 0.373, Re = 0.78, via the heavy-sphere trick below) removes the inertia confound entirely, and the agreement over the mid-range tightens to ±2–5% for gaps of 0.25 R to 2 R. The departure points then land cleanly, and refinement moves them the right way — at a fixed absolute gap the error shrinks with h (at ε = 0.1: L3 −19.2%, L4 −12.7%). RECORDED

The reference — Beetstra, van der Hoef & Kuipers (2007)

The Beetstra paper is not a theory paper; it is a large measurement campaign. The authors ran lattice-Boltzmann flow through static random arrays of spheres over 35 combinations of packing fraction and Reynolds number — φ from 0.10 to 0.65, Re from 10 to 1000, resting on their own earlier Re → 0 dataset — and fitted the result into a drag correlation. That correlation went on to become a standard closure input for Euler–Lagrange and two-fluid models of dense suspensions and fluidised beds, which is to say it is exactly the kind of closure the EL campaign spent two months validating. Measuring the same quantity from the resolved side is the bridge between the two campaigns, and the concrete content of the D5 “DNS-informed EL” deliverable.

The configuration is close to what this machinery already does: N spheres placed at random in a fully periodic cell, non-overlapping and held fixed, with a constant body force — equivalently a mean pressure gradient — driving flow through the array. The measured quantity is the mean drag per particle as a function of φ and Re. Because a random pack is a sample rather than a geometry, the reference is an ensemble statement: no single arrangement is obliged to sit on the curve.

There are conventions to get right, and they are worth stating plainly. Their F is the drag part only. A particle in a driven array feels both surface friction and a buoyancy-like pressure-gradient force −V_p∇P; the correlation excludes the second, so F_d = (1 − φ) · F_total — while a momentum balance, which is what we measure, gives F_total. Their normalising velocity is the superficial U = (1 − φ)u₀ (eq. 1), and their Reynolds number uses that same superficial velocity (eq. 2). The Stokes-limit fit is a modified Carman form, F(φ,0) = 10φ/(1 − φ)² + (1 − φ)²(1 + 1.5√φ) (eq. 6), normalised so that an isolated Stokes sphere gives exactly 1.

As a validation target it plays the part for many spheres that Hasimoto played for one — a genuinely periodic flow judged against something outside our own code. Two things differ. The reference is ensemble-fitted data rather than a closed form, so agreement has to be read against seed scatter as well as against discretization. And the output is not only a check: it is the drag law the EL side needs.

A second periodicity defect — the FBM indicator is not periodic either

This is a sibling of the D1.1b communicator defect, in a different layer, and the probes caught it by a volume audit. A sphere whose centre sits near a periodic face loses the part of itself that lies outside the box: the indicator simply does not wrap. With 8 of 16 spheres straddling a face, the measured solid fraction came out at 0.0441 (L3) → 0.0435 (L4) against a nominal 0.05 — and the giveaway is that it converged the wrong way, toward the Monte-Carlo value for un-imaged geometry, 0.04301. Refinement was faithfully resolving truncated spheres. D1.1 never saw this because its single sphere sits at the cell centre.

Fix for fixed arrays — the generator emits explicit image spheres, which is solver-free and exact. Solid fraction returns to +0.16% (L3) and +0.05% (L4) of nominal, and the flow visibly changes: the superficial velocity drops as it has to squeeze past whole spheres rather than clipped ones. Recorded limitation. That fix works because the geometry is static. Moving particles crossing periodic faces need real periodic support in the FBM classifier (and in PE), which does not exist yet — flagged for the dynamic D3 stages and for any EL periodic re-run in which particles wrap. RECORDED

Third convention pin — and it accounted for the entire apparent discrepancy

The raw comparison sat +14 to +53% above Beetstra, and the excess grew with φ — which looks exactly like a physics problem, and for a while was treated as one. It was not. Reading the force split off the paper itself (pp. 490–491) fixes F as the drag part alone, so the measured total must be multiplied by (1 − φ) — a correction that grows with φ in precisely the way the discrepancy did. With that applied, and the superficial-velocity normalisation of eq. (1), the excess collapses to single digits at every φ.

This is the third time in this campaign that an apparent result turned out to be a convention — after Hasimoto's F and, separately, his U. The pattern is consistent enough to be a working rule: pin the reference's own definitions, from the reference's own text, before believing a discrepancy. RESOLVED

Why this matters beyond D3.1 — a closure implication for D5

If instantaneous drag varies by tens of percent with local arrangement once Re ≳ 20, that dispersion is physical, not noise — and it is exactly what a mean-field closure integrates away. Every EL and two-fluid model built on an ensemble-mean correlation carries one number where the resolved flow has a distribution. A DNS-informed EL closure is in a position to carry the fluctuation as well as the mean, which is a capability the correlation literature cannot supply from ensemble fits alone.

Risks and standing decision points

  1. Cost blow-up is the main risk: resolved DNS scales as (D/h)³ per particle per level. Mitigation: D1's cost table is a gate for D3.2/D3.3 scoping; every stage sizes N and resolution from measured cost, not hope. Descopes are recorded, not hidden.

  2. q2p1_dns_drag is serial-PE-only (parallel path aborts by design). Fine for fixed arrays (no PE dynamics needed), but rank-count-limited via the CFD side; if L4 arrays are needed, either extend the setup to parallel PE or accept the resolution ceiling — decision at D3 design.

  3. Grid-crossing noise may dominate tolerances at affordable D/h; if D1.2 shows a large noise floor, gates shift from instantaneous values to time-averaged/filtered observables (state the filter in the RUNBOOK).

  4. DKT chaos: post-contact trajectories are not gateable; the design pre-commits to pre-contact observables so a FAIL cannot be argued away.

  5. Two ten Cate meshes (quarter benchSym vs full box) are different discretizations; every cross-comparison states which is used. The quarter-box symmetry assumption itself gets one full-box vs quarter-box twin row in D1.

  6. Parallel-PE Cartesian partitioning depends on the unmaintained METIS-4 tools/partpy path — D0.1 must produce a supported recipe before any parallel-PE campaign runs.

  7. FullC0ntact backend is out of scope except D4's OBJ-mesh twin; recorded so the campaign's claims are clearly scoped to the PE backend.

  8. Existing DNS regression baselines were produced under HardContactEulerLagrange builds (including the committed featflower_test sedimentation baseline). The D0.6 solver split therefore needs its own equivalence twin, and baselines are re-pinned under the DNS solver once that twin is green — never silently reused across solvers.
