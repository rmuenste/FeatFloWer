# Mesh: pipe_ogrid_z (PIPEZ27)

Straight circular pipe, axis z, generated by `hex_ex.py` (user-provided,
2026-07-03), adopted for the EL validation campaign per the pipe-mesh spec.

- Radius R = 0.5 (analytic-cylinder hull, `hull.par` type-7 descriptor
  `7 0d0 0d0 0d0 0.5d0 1d0 1d0 0d0`: center origin, project x/y, z free).
- Length L = 2.0 (= 4R), z ∈ [0, 2].
- Coarse: 1296 hexes = 48-cell O-grid cross-section (4×4 core + 16×2 ring)
  × 27 uniform axial layers (Δz = 2/27). 1596 vertices, 57 per plane.
- End faces z=0 / z=2 are exact translated copies (verified point-set identity)
  and tagged `Periodic` (non-BC tag; coupling is done by the dPeriodicity DOF
  matcher with `SimPar@PeriodicAxis = z`, `SimPar@PeriodicLength = 2.0`).
- Partitions: `partitions/PIPEZ27/sub0001..sub0027` — 27 axial slabs
  (one coarse layer each), matching PE `processesX_/Y_/Z_ = 1/1/27`.
  (The partition folder also carries small generator visualization files
  `main.vtu`/`subdomains.pvd`; they are unused by the runtime.)

## Resolution at run level (MaxMeshLevel = 3, two refinements)

- In-plane spacing ≈ 0.025 (interior), axial ≈ 0.0185.
- Kernel width δ = 2.5·d_p = 0.125 for d_p = 0.05 ⇒ δ/h ≈ 4.5–6.7 in the
  interior — meets the ≥4 target.
- KNOWN SOFT SPOT: the outer O-grid ring has 16 tangential cells at coarse ⇒
  tangential spacing ≈ 0.049 at the hull (δ/h ≈ 2.5 in that direction only),
  improving with radius (≈ 0.029 at the Segré–Silberberg annulus r = 0.3).
  Particle centers cannot approach closer than r ≈ 0.45 (wall exclusion),
  where the spacing is 0.044. The level-2 vs level-3 Hagen–Poiseuille pair
  quantifies the impact; fallbacks are MaxMeshLevel = 4 (663k elements) or a
  regenerated O-grid with 24 tangential ring cells.
- Element count at level 3: 1296 × 64 = 82,944 (~3k per subdomain at np 28).
